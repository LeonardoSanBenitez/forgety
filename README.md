# Forgetsy

A web platform to ease the use of the [Vision Unlearning](https://github.com/LeonardoSanBenitez/vision-unlearning) library.

# Getting started

Local file `.env` is required.

Run in the terminal, from the root folder:

```bash
docker compose up
```

then go to `http://localhost:8501`

See also the backend documentation at at `http://localhost:8001/docs`.
